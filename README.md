# Cray Supercomputer Code Search — Oldest First

A research project of Douglas Roy Schoonover, started November 10, 2026, under his standing rule: *any internet-search project starts as a GitHub project and is worked that way.*

**The question:** what code for the Cray supercomputers themselves still survives in public — operating systems, compilers, assembly, emulators, manuals with code — and where does it live?

**The method (his):** oldest first, always. Learn from the oldest material first so you don't get overwhelmed, then work your way up era by era. Holes in the record are labeled **[GAP]**, never guessed at. Public sources only.

**Companion shelf:** [ai-supercomputer-history](https://github.com/schoonoverdouglas1-png/ai-supercomputer-history) — the TPU-vs-Cray lineage project this search feeds.
